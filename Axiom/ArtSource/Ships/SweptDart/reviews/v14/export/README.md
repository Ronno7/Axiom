# Swept Dart import package

Everything the ship needs for its Unity import, which hasn't happened yet.

| File | |
| --- | --- |
| `SweptDart.fbx` | The ship |
| `SweptDart_Interior.fbx` | Interior, shown only while it builds |
| `SweptDart_Construction.fbx` | The 91 construction traces |
| `HullArrival.exr`, `TraceTimeline.exr` | Baked build timing |
| `Shaders/` | URP shaders, not compiled yet |
| `material-bindings.json`, `package-manifest.json`, `timeline.json` | Materials, mesh data and trace timing |
| `validation.json`, `data-validation.json` | Blender checks |

Reviewed in Blender: [stages](../qa/sequence-sheet.jpg), [playback](../qa/runtime-sequence.mp4) and
[shield states](../qa/shield-sheet.jpg).
