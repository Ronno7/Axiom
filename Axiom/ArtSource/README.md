# Art source

Editable sources for the game's art, outside Unity's imported `Assets` folder. Historical studies, Blender
ship files and research material are kept locally and aren't in this repository.

| Folder | Contents |
| --- | --- |
| [Ships/SweptDart](Ships/SweptDart/README.md) | Player ship: import package, showcase renders and build scripts |
| [Palette](Palette/) | Shared color tokens and palette generation and check tools |
| [Title](Title/) | Editable title model and generator |
| [Icon](Icon/) | Application icon generator |
| [Fonts](Fonts/) | Supporting typeface license |
| [earth-orbiter](earth-orbiter/) | The title's font and its license |
| [Audio](Audio/) | Sound generators |

Imports and scene integration are separate steps; these folders aren't copied wholesale into `Assets`.
